# 润色中文技术文档

先确定读者、使用场景和编辑范围。标记需要保留的术语、命令、字段名、数字、单位、责任人、时间条件及约束力度。

1. 把结论放到读者需要它的位置，紧接着写依据或适用条件。把空泛的程度词换成原文已有的证据，或直接写发生了什么。
2. 把难读的名词堆叠改成带有动作和对象的句子。列表用于可扫描的步骤或选项，表格用于字段和对照关系。沿用文档已有的术语和格式。
3. 核对改写前后每项事实、条件和语气。特别检查假设是否写成了定论、可选项是否写成了要求、计划是否写成了已完成。保留代码块和命令的技术含义。

按用户指定的方式交付改写。原文有影响理解的歧义时，保留原信息并指出需要确认的地方。
