# 评审技术方案

读取用户给出的方案和它引用的需求。对链接使用已授权的读取工具。先确认目标、范围、约束与验收口径，并记录会影响结论的资料缺口。

按方案涉及的内容检查以下问题。

- **需求与架构** 用户路径、异常路径和边界需求是否都落到设计中。模块职责、数据归属和依赖方向是否清楚。
- **契约与数据** 旧客户端、存量数据及新旧版本共存期间如何工作。写入失败、重复请求、并发更新和迁移中断后如何恢复。
- **运行条件** 关键权限和数据访问边界、容量假设、延迟目标及依赖故障的影响是否有依据。
- **交付与运维** 验收场景是否可观察。灰度范围、监控信号、回滚触发条件和数据恢复步骤是否足够具体。

逐项引用章节、原有契约或代码证据，写清触发条件、后果和建议补充的决策。区分会阻塞实施的缺陷、可在实施中解决的改进，以及待补证据的问题。结尾给出是否进入实施的建议及前置条件。
